How to play & save your progress

Each accepted answer adds 10–100 points and lifts your rocket by 10 km per point. One accepted answer per prompt. Small spelling mistakes and distinctive shortened names are accepted. Ambiguous answers need more detail. Unknown answers do not cost points; you can try again while the timer runs. Skip a prompt for zero points. Choose “Next prompt” when ready.

The daily is the same seven general-knowledge prompts for everyone on that UK date (Europe/London). Each pilot can record one completed daily per date; unfinished flights can be restarted. Practice is unlimited, with a separate shuffled deck for each difficulty. The bank is finite, so questions will eventually repeat. Crew challenges use a match code and chosen difficulty; compare results yourself or play on the same browser.

Anyone using this browser can choose any pilot. Clearing site data removes profiles. Work computers may clear data automatically. Export a backup regularly; importing replaces this browser’s profiles. Use one game tab at a time.
